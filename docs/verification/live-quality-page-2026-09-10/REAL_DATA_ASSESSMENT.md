# 真实数据 RAG 评测：现状判断与待确认方案

2026-09-10。本轮为代码与研究核查，没有导入真实客户数据、修改评估器、执行新模型调用或完成真实数据评测。数据来源尚待用户回答。当前事实仍以 docs/STATUS.md 为准；本文是评测设计输入，不新增产品路线。

## 已核查的事实

- app/data/knowledge.json 只有 10 个 chunks，jq 检查确认。
- evaluation/data/live-quality-v2.json 明确标记 SYNTHETIC，包含 22 例，已用于多轮修复，适合作为已知问题回归集，不是未见问题测试集。
- evaluation/citation_validation.py 的 citation_ids_are_valid 检查引用 ID 与 expected/retrieved/allowed 集合关系，没有逐句判断证据是否蕴含回复陈述。
- evaluation/live_summary.py:11-18 使用全部案例汇总部分指标；:53-55 在没有无证据案例时返回 1.0，存在把无样本呈现为满分的风险。不能把这种值作为已测安全率，未来应显示 N/A 并给出分母。
- live_reply_checks.py 的政策模式与字符语言检查是有限规则，不代表完整语义审核。
- Java EvaluationReportReader.java:103-110 把 live 汇总映射到通用质量页字段；标签与分母仍需澄清。当前 20/22 是特定机器检查结果，不是人审答案准确率。

正常例：引用有效且答案确实受原文支持，可以通过结构与语义检查。失败反例（说明用，未运行）：引用了正确退款文档，却把“审核通过后到账”写成“已退款”；当前引用 ID 检查本身无法辨别这种语义错误，必须由独立语义审核确认。来源绑定规则能约束列明主题，但不能证明所有主题正确。

## 待确认的数据来源

优先使用获准处理的历史工单、当时可见的业务知识与人工处理依据。工单正文脱敏并保留业务条件；问题输入不得包含后续客服答案。冻结文档时间、产品版本与权限，避免使用问题发生后才生成的答案泄漏。

没有内部数据时，先选择一个产品领域，以独立真实公开问题配合同领域官方文档构建基准；可考察 TechQA。公开基准只证明对应公开任务，不能证明本项目真实客户分布。下载或导入前确认实际数据可获取性与使用条款，不将代码许可证当作数据许可；本轮未下载。

## 建议的首批验收设计（计划中）

1. 先用 20–30 个独立真实问题试标注，暴露缺资料、版本和标注分歧。之后可从约 200 个独立问题起步，例如 50 个开发集、150 个冻结测试集；这是项目启动规模建议，不是统计充分性或行业标准。
2. 同一会话、故障、重复模板及改写必须分在同一集合；优先保留时间外测试。正常分布与安全挑战集分别报告，不用挑战集比例冒充真实流量。
3. 标注可答/需补问/知识缺失/需授权或转人工，原文证据位置与版本、必须回答要点、禁止承诺、可接受替代证据、标注人和分歧。原文位置映射到实验 chunk，避免换分块就改变正确答案。
4. 测试问答与评估答案不得写进可检索 corpus；实际业务原本可访问的知识文档可以保留，冻结时间必须明确。不要只索引每题正确答案，应保留真实干扰文档。
5. 单独测检索 Recall@K、MRR、上下文相关性；生成测逐条主张支持、关键要点覆盖和引用支持；行为测拒答正确率与可答题误拒答率；运行测超时、端到端延迟、尝试次数、用量与成本。无样本的指标为 N/A。
6. 主要业务结果定义为人工确认的“正确且有据的处理建议/全部测试请求”，适当补问或升级可按预先标准成功，超时及未知错误不算质量成功。保留条件成功率用于定位，不能从总分母剔除失败。
7. 在相同 corpus、问题、模型、上下文预算与规则下比较 BM25 与当前向量检索；可另加不检索、人工给定正确证据的诊断对照。逐案例配对比较并报告不确定性；重复运行不增加独立问题样本数。
8. 人工先盲审冻结测试输出；高风险案例和分歧复审。LLM 可预标注，但须用独立人工标签校准并记录误判，不能把其分数当人工事实。分开报告原始模型候选与规则约束后的系统输出。

验收应交付数据来源清单、文档快照、集合划分、标注表、冻结配置与源码摘要、全部运行结果、人工审核和失败清单。当前尚未产生这些真实数据验收物。

## 研究依据

- [RAGAS](https://arxiv.org/abs/2309.15217)：区分检索上下文与生成回答的评估维度；自动指标不能替本项目完成人工审核。
- [ARES](https://arxiv.org/abs/2311.09476)：结合自动评估与人工标注估计 RAG 质量，支持对自动裁判进行人工校准的方向。
- [TechQA 原论文](https://aclanthology.org/2020.acl-main.117/)：技术论坛真实用户问题与 IBM 技术文档配对；属于公开技术支持任务，非本项目客户数据。
- [IBM TechQA 仓库](https://github.com/ibm/techqa)：官方说明榜单已停止维护，数据仍提供使用入口；本轮仅核查说明，未验证完整下载。
