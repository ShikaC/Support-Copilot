# 调用前协议修订：机构信息与输入载体

初版协议和抽样原件保留不覆盖。审计新候选时发现 `dmv → Virginia DMV` 没有来源支持：候选 0 的文档提到 NY State，而该 user 对话没有州别。仅凭域名补入 Virginia 会制造错误上下文。

本修订发生于任何新模型/Embedding 调用之前，不变更抽样盐、候选清单、顺序、split 或不递补规则。`candidate-inputs.json` 是含这项错误的原始准备记录，**不得直接用于模型输入**；运行允许使用的投影只来自 `cases.json` 的 `input`。

- DMV 路由改为 `DMV (state/jurisdiction not provided by routing)`。原 user 明确提供的 New York 保留在原句中；其他题不从文档 ID、目标回复或跨度补出州别。需要适用州别的题归入 CLARIFY。MyDMV 产品名若仍有州别歧义，也须记录待确认项。
- 其余域仅提供机构级路由，不补具体福利、资格或业务状态。此统一路由是实验上下文，不能冒充真实对话原文。
- DIRECT 可回答一般规则/条件性流程，不要求用户提供与该一般问题无关的个人细节；但涉及其本人资格、适用流程的缺失条件要 CLARIFY。给出有依据的条件分支并询问缺失条件可通过补问评分，不要求逐字固定问句。
- 每题 `input` 仅包含中性标题、固定历史语料说明、机构路由及原对话前缀；对话拼入工单 description，参考答案、source、audit 均只在离线文件。CLARIFY 也不向模型传递“该题需补问”标签。未来 runner 必须只发送这两个输入字段，不能发送整份 case。
- 去重同时比较文档 ID、去掉 `#...` 后的来源标题、规范化全文和输入词集合；近重复候选须显式解释，不因通过字符串校验就声称语义无重复。
- 真实公开 issue 的源正文短且无个人账号/凭据，保留原始正文用于 hash 验证，但只发送通过纳入审计的必要问题片段。含事后答案的 #2661 排除；不通过截掉答案把它重新包装成盲测题。

这次修订说明离线审计捕获了一个真实准备层错误。初版输入没有送入项目模型，也没有污染旧 run-1。所有人工审核字段继续为 NOT_REVIEWED。
